## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not open a public issue**. Instead, follow these steps:

1. Send an email or private report detailing the vulnerability.
2. Include steps to reproduce the issue, potential impact, and suggested remediations if available.
3. We will review your report promptly and provide a resolution plan.

Thank you for helping keep this project secure!
