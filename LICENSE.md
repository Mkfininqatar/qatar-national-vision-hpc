# Contributing to Qatar National Vision HPC

Thank you for your interest in contributing to the **qatar-national-vision-hpc** project! Whether it's bug fixes, documentation improvements, or new features, contributions are welcome.

## How Can You Contribute?

### 1. Reporting Issues
If you encounter any bugs, performance bottlenecks, or have feature requests, please open an issue on GitHub. Make sure to include:
* A clear and descriptive title.
* Steps to reproduce the issue (if applicable).
* Expected vs. actual behavior.

### 2. Proposing Changes
1. **Fork the repository** on GitHub.
2. **Clone your fork** to your local machine:
   ```bash
   git clone [https://github.com/Mkfininqatar/qatar-national-vision-hpc.git](https://github.com/Mkfininqatar/qatar-national-vision-hpc.git)
Create a new branch for your feature or bug fix:

Bash
git checkout -b feature/your-feature-name
Make your changes and commit them with clear commit messages:

Bash
git commit -m "Add: description of your changes"
Push to your branch:

Bash
git push origin feature/your-feature-name
Open a Pull Request against the main branch of the original repository.

Code Standards
Keep code clean, well-commented, and aligned with high-performance computing telemetry and digital twin simulation protocols.

Ensure your changes do not break existing telemetry scripts (hpc_telemetry.py) or configurations.

Thank you for helping advance this project!
